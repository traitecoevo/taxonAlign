`apcalign_test_matches_alignments_updates.csv` is APCalign's own benchmark of 239 hand-checked names
(traitecoevo/APCalign, `tests/testthat/benchmarks/test_matches_alignments_updates.csv`, MIT licence),
copied 2026-11-14. `test-apc_equivalence.R` runs these names through both APCalign and taxonAlign on
the same live APC data and compares the results column by column.
